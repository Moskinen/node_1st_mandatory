GET Request over HTTP

There are two ways of sending and recieving data in express over HTTP.
One being query paramaters and the other being URL parameters

Query Parameters: The thing after ? in the url.
Example: /plants?name=cactus
To then acces the data with a get request, req.query.(key) is used:
app.get('/plants', (req, res) => {
 const name = req.query.name
 res.send(name)
})

URL parameters: After the "/" after the api name
Example: /plants/5
To then acces the data with a get request, req.params.(key) is used:
app.get('/plants/:id', (req, res) => {
 const const id = req.params.id
 res.send(id)
})

Learning Goals

Understands how to send data with GET requests over HTTP and knows how to do it in Express.
Can make a POST request and parse the body in Express.
