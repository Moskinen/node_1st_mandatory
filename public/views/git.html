GIT

git terminal commands

"git clone $url" clones github url to a local path
"git add" staging changes
"git commit" commiting staged changes
"git push" pushing the commited changes
"git pull" pulls the latest changes

git branch commands

"git checkout -b $branch name" creates a branch with a given name
"git checkoout $branch name" goes to a branch with a given name
