Modules

CommonJS vs ES modules

Node.js supports commonJS and ES modules.
CommonJS was the original and uses require() to import and module.export to export.

ES Modules is now the standard module system, it uses the same import and export syntax as browser in Javascript
The syntax being the same helps with standardization.
Example on import an export with ES modules

export const frontpagePage = constructPage(fronptage);
I can then import the frontpagePage in another file with the following statement:
import { frontpagePage } from './templating/pages.js'

Learning Goals

Can work with both types of import/export in HTML.
Can import/export in both ways in Node.js (CommonJS and ES Modules). Knows the pros of using ES Modules.
