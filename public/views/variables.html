Type coercion

In Javascript type coercion is when you do an operation on different data types and js tries to make them fit together by changing the data type to another

Example:
let result1 = ('5' + '2'); // = 52
let result2 = ('5' - '2'); // = 3

One way to avoid this is by using "===" also known as strictly equal.
This will only return true if both the value and data type is equal

Data types

Strings, Boolean, Number, BigInt, null, undefined, Object, Symbol

Arrays

Like in Java, in JavaScript we use square brackets to instantiate an array.
To add to an array we use .push and take remove from an array we use .pop
If we want to print two elements of an array it's important that we dont use "+"
We should use "," since + "+" can concatenate or coerce the data type

const things = ["mouse"]
things.push("car")
console.log(things[0])
console.log(things[0], things [1])

Quotation

For quotes both ", ', and ´ can be used. However if anything but backticks is used you will not be able to use $ to string interpolate.

var, let, and const

const is the default, while you should use let if you should reassign the variable. You should never use var, since it can "bleed out" in other scopes, and be changed in different files. 

    
{ Block scope
    var someValue = 123;
    {
        var someValue = 456;
    }    
    console.log(someValue)
}

let can change, but always within scope
{
    let someOtherValue = true;
    {
        let someOtherValue = false;
    }
    console.log(someOtherValue);
}
