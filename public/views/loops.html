Loops

Rules about loops in JavaScript

Rule #1: Use loop methods in JavaScript
Rule #2: Dont use for loops in Javascript, unless you are finger counting
Rule #3: Use .map if you need the data afterwards, otherwise only use .forEach if you dont

Loop Methods

Following are loop methods in Javascript:
.forEach .map .filter .reduce .find findIndex .indexOf
.map: returns a new list of the same size
.filter: returns a new list of a smaller size
.find: returns one thing

Code Examples:

Example on use of map:
const doubledNumbers = numbers.map((number) => number *2)

Example on use of filter:
Precondition: There is a data structure names countries with a key named gdp
const countriesWithGPDOVer1000 = countries.filter((country) => country.gdp > 1000)

Learning Goals

Can use loop methods (+map, +filter). Can choose the right one at the appropriate time:
Understands why a functional approach to loops is to be preferred and how to implement it without side effects.
