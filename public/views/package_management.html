Package Management

NPM (Node Package Manager)

Is a package manager, like maven, used to install and keep track of dependencies.
in the package.json file all dependencies are listed with the follwing syntax.
{
 "dependencies": {
  "express": "5.2.1"
 }
}
Running npm install followed by the package will then create node_modules which contain the downloaded package.
node_modules should not be pushed, since we dont want to force all the packages on other developers.
The package.json file is pushed, so other developers can download the packages themself

Learning Goals

Understands the function of NPM and can compare it with other package managers.
Understands the different purposes of package.json and can set it up by hand.
Understands what node_modules are and why they shouldn’t be pushed.
