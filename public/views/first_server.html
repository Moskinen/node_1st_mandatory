First Server

Express

Express is a very light web framwork, that is used to create servers and handle http requests
Following is an example on how to set up a server with express:
Precondition: The dependency is downloaded like it's explained here

const express = require('express')- Import
const app = express()- Instantiate
app.use(express.json())- Use

Client Server Model

Client: Sends a request to a server (could be a browser)
Server: Recieves the request, and sends a response back (could be your express server)

URL Terminology

You need to understand different parts of a URL to know how to retrieve data from it
Following is an example of a URL:

https://localhost.com:8080/plants/5?name=cactus

http:// Is the protocol
localhost is the domain
8080 Is the port
/plants/5 Is the path
?name=cactus Is the query string

GET Request over HTTP

There are two ways of sending and recieving data in express over HTTP.
One being query paramaters and the other being URL parameters

Query Parameters: The thing after ? in the url.
Example: /plants?name=cactus
To then acces the data with a get request, req.query.(key) is used:
app.get('/plants', (req, res) => {
 const name = req.query.name
 res.send(name)
})

URL parameters: After the "/" after the api name
Example: /plants/5
To then acces the data with a get request, req.params.(key) is used:
app.get('/plants/:id', (req, res) => {
 const const id = req.params.id
 res.send(id)
})

Serving Static files

To make html, css, js, images, and such accesible to the client, we need to serve them.
It can be done like our get methods, but a better approach is serving all static files through af directory
app.use(express.static('public'))

Then in our public directory we will have a file structure icluding css, html, js and picture.
But we have to make sure only client side files will be served. It can be a safety issue if sever side code is exposed

Learning Goals

Can create a server with Express from memory.
Can explain the client-server model.
Understands the security need to serve static files and can do it in Express.
