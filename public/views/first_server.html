First Server

Express

Express is a very light web framwork, that is used to create servers and handle http requests
Following is an example on how to set up a server with express:
Precondition: The dependency is downloaded like it's explained here

const express = require('express')- Import
const app = express()- Instantiate
app.use(express.json())- Use

Client Server Model

Client: Sends a request to a server (could be a browser)
Server: Recieves the request, and sends a response back (could be your express server)

Learning Goals

Can create a server with Express from memory.
Can explain the client-server model.
