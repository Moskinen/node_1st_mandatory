Rest API

Three rest API conventions

#1 Using the right HTTP verb:
GET: Retrieve data
POST: Create data
PUT: Originally used to replace an entire row, now it's also used to partially change a row (what used to be patch)
DELETE: Delete data

#2 The order of the methods
To make it easier to read the code for you and other developers,
the order of the methods is important. It should be as listed above.

#3 Naming (Noun plural)
Always use the plural noun of the concept the api is being designed for

Learning goals:

Can design a REST API.
Knows the three REST conventions we follow
